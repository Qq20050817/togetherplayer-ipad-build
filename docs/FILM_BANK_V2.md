# TogetherPlayer 电影 AI 题库 V2

V2 是功能方案名称，正式文件仍使用现有 `schemaVersion: 1`，字段名称以 `question-bank-v1.schema.json` 为准。

## 使用

1. 在 iPad 加载本地原片，在“剧情推理室 → 制作 AI 电影题库”点击提取。优先当前选择的内置字幕；不能读取时使用已导入的完整外置字幕。PGS 仅在独立素材扫描中本机 OCR，不改观看轨道。
2. 保持 App 前台，等待提取完成。可取消；切换原片会取消旧任务。进度失败不会发布半成品。文件保存于“我的 iPad → TogetherPlayer → AI素材”。
3. 素材包含 `manifest.json`、完整 SRT、带时间码的分镜 JPG、`frame-timeline.json`、正式 Schema 与 ChatGPT 项目指令。可分享 ZIP、全部独立文件，或在菜单中单独分享某个字幕/分镜/Schema；也能从“文件”中选择。分镜预览包含全片剧情，请在制作题库时查看。
4. 在 ChatGPT 新建电影题库项目，使用 `CHATGPT_MOVIE_BANK_PROJECT.txt`，上传上述全部素材。聊天平台无法处理 ZIP 时改传独立文件并分批补齐。ChatGPT 需要真实查看所有分镜和完整字幕，不能仅凭片名、局部对白或抽象简介出题。目标 5～10 题，围绕核心冲突、人物目标和事件因果，低价值题删掉，不强行凑题。
5. 将纯 JSON 保存到“文件”，在 App 导入。指纹/时长必须与原片匹配；不同剪辑或转码文件首版不自动套用。先用少量首尾数据查候选，未找到题库不读取完整大文件；候选绝不代替完整SHA256最终核验。题库按原片完整 SHA256 保存，换房间、文件移动、重启后可恢复匹配题库。
6. iPad 房主正常播放时跨过题目时间，等待当前字幕句末，使用现有房间协议发题并同步暂停；双方独立回答，按现有规则恢复。一个人在线也沿用服务器单人答题规则。
7. 正确答案和未来证据留在房主本地，初次发题仅发送题干/选项。房间、房主和在线另一端的进度达到揭晓点后，通过现有聊天通道发送答案和完整解释；长解释分段发送，使用稳定消息 ID，服务端已有去重。iPad 管理面板也显示完整揭晓文字。Android 可在房间聊天中查看。
8. 本轮已发题、已完成答题和已送达揭晓记录持久化；普通回退不重置。“开始新一轮题库”需确认，只重置本轮进度，保留 JSON。没有题库时不会后台自动请求旧版 AI，旧版手动入口仍保留。

## 时间与格式

- 全部毫秒。题库的 trigger/reveal 使用原片文件时间；房间偏移仅在同步/双方揭晓门槛处换算。
- 提问证据 `endMs <= triggerAtMs`；`triggerAtMs < revealAtMs <= durationMs`；后续证据必须位于触发之后且在揭晓之前。
- 有答案需要正确索引、揭晓时间与揭晓证据。开放讨论使用 `type: discussion`、`answerIndex: null`、`revealAtMs: null`、`revealEvidence: []`。
- 必须包含 Schema 中要求的 nullable 字段，不能省略；不接受额外字段、重复编号/问题/触发点、不合法类型或影片身份。用户可见错误不会直接崩溃。
- `sourceFingerprint` 现在为完整文件 SHA256，旧版“首尾采样”指纹的素材须重新导出。旧 JSON 保留，不会被静默删除或套到不匹配原片。

## 实际边界

- 提取使用独立 AVFoundation/FFmpeg 解码器，不移动播放器。约60秒基础采样，补充长对白间隙、字幕变化和相邻样本亮度直方图变化附近的截图小组；为基础时间线保留配额，上限250帧。它是启发式采样，不是完整语义镜头检测，也不能证明帧间动作。`actualMs` 是实际解码时间；manifest 会记录未取得的请求帧。缺帧超过20%则明确失败，不假装完整导出。
- AVFoundation 使用 SDR 输出；FFmpeg PQ/HLG 缩略图经预览用色调/色域变换。真实 HDR/Dolby Vision 视觉质量、4K 长片资源占用及所有 MKV 编码组合仍须真机验证，合成样本通过不代表全部支持。
- JSON 静态检查可拦截格式和时间证据错误，不能证明 AI 在语义上完全正确或完全无剧透。ChatGPT 项目应逐题审核；confidence/qualityScore 不是验证准确率。
- 没有额外付费 API 依赖。素材只由用户手动分享；ChatGPT 自身套餐/附件/上下文限制仍适用。正常导入题库观影不调用 ChatGPT 或苹果模型。
- 当前复用现有同步暂停/投票和聊天协议，不部署或重启服务器、不改数据库、路由器、Muse 或 Android 安装包。仍需一次 iPad+Android 双真机验收，未完成前仅作为预览交付。

## 恢复

安装前备份所需 JSON/素材，用原证书签名覆盖，保留应用数据。代码基线为已验证 0.6.32（公开 `6affce9f70bc94c622bc8f263d6108ef810a84dc`，CI `38777100480`），其来源为 0.6.31 `327c6dacd1b51e1d40f1388d65937881cacc78e9`。独立分支 `feat/film-bank-v2-completion-20261016`，不覆盖旧分支或 main。回退保留旧 IPA，并单独备份本次导入题库。公开仓库历史 server 目录不是线上服务有效源码，不用于部署；有效服务器代码以私有仓库与既有交付记录为准。
