# Android 0.5.9：兼容播放器的内置字幕

修复本地兼容播放进入或退出全屏时，LibVLC 的视频/字幕 Surface 随旧窗口销毁后没有重新绑定的问题。输出随窗口生命周期重新绑定，并恢复用户选择的内置字幕轨道。切换到新片源会清除旧轨道选择；关闭字幕保持关闭。

回归使用实际内嵌 SRT 与 PGS 的 MKV，通过屏幕截图像素差检查字幕确实出现在画面上，并覆盖跳播、进入全屏、关闭字幕、退出全屏。PGS 测试包含连续的完整调色板/图像字幕包；跳过单个字幕图像后，测试等待后续完整字幕，而不是假设丢失的图像可以凭空恢复。

原有解码兼容、文件匹配、同步和语音功能保留。云端模拟器不能替代目标平板和原始电影的实机验证。
