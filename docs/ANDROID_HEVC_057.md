# Android 0.5.7：HEVC 运行时解码回退

用户反馈：小米平板 7、0.5.5，本地 HEVC 影片在系统相册正常播放，TogetherPlayer 报 ERROR_CODE_DECODING_FAILED。

实现：保留启动阶段的 Media3 回退；运行时 HEVC 视频解码失败后排除失败解码器，查询支持当前格式的另一设备解码器，同一片源最多尝试两次。重新准备同一个播放器及当前位置，保留外挂字幕，沿用房间原有同步和播放状态，不主动自动播放。无备用解码器时明确报错，不能声称软件解码已内置。

增加视频解码器名称、设备型号、尺寸、编码 profile 字符串等现有诊断事件信息。提示不再直接归因于“设备不支持 4K”。不上传影片或录音。

不修改 iPad、服务器、数据库、路由器和语音模块。没有小米平板实机及原始影片，模拟器不能证明用户这部影片已经恢复。

测试：回退次数/失败排除/同源持续限制/换源恢复/无候选和非 HEVC；原生播放器恢复路径与真实 HEVC 短文件首帧/重新显示首帧、位置与外挂字幕保留；已有同步、音频、语音及界面回归。
