# TogetherPlayer 0.5.2 语音弹幕测试版

本次开发在 `feat/voice-danmaku` 分支进行。iPad 基于已验证的 0.4.8 源码，Android 基于 0.4.1。主观影服务、房间数据库、路由器和其他自动化服务未改动。

## 使用

加入房间，在画面附近点击「启用语音弹幕」，允许麦克风（iPad 还需要语音识别权限）。按住「按住说话」录音；上滑后松手取消，直接松手进入识别结果预览。可以修改结果，只有点击「确认发送」才向房间发送文字。最长默认 60 秒，可选 30 / 60 / 120 秒。达到上限也只生成预览，不会自动发送。

语音设置中可调收音提示阈值和文字上限（120 / 300 / 500 字）。阈值仅帮助查看是否收到足够响的声音，识别使用完整音频，避免切掉轻声、字头。幅度无法区分你和电影里的说话人。已有识别文字会保留到可编辑预览，最终回调为空或出错时不直接清空。iPad松手后已有文字最多等待700ms收尾；没有文字时给本地识别3秒。

录音时影片继续播放，播放器音量用480ms平滑过渡：两端内置扬声器降至静音，耳机降至原音量的22%，结束后恢复。录音期间手动改变音量时，恢复到新设的音量。iPad在启用语音时准备一次音频会话，按住/松开不再反复设置会话类别和首选输入；仅按住时采集，关闭语音/后台/离开房间恢复原会话。模块不调用电影的播放、暂停、跳转或变速。录音、收尾、预览期间全屏控制保持可见。取消、断线时停止采集并取消未发送内容。

## 本地识别和隐私

- iPad 使用 Apple 本机中文识别，强制 `requiresOnDeviceRecognition`。系统未提供本地中文识别时明确提示不可用，不切换到云识别。保留 A2DP / 有线播放输出，采用设备内置麦克风；路由无法保持时关闭语音并恢复原会话。未启用会切换到蓝牙通话音质的 HFP / voiceChat。
- Android 使用 Vosk 免费离线中文小模型，约42MB模型已随APK提供，首次启用在本机校验、解压约68MB并载入，无须网络下载。准备过程显示进度，可取消或失败后重试。官方 Apache 2.0 模型地址、SHA-256 和许可证随源码提供。模型完整性校验、解压路径和大小均受检查。音频采集和识别在工作线程，电平/部分文字最多每秒刷新四次。
- Android 设备提供 AcousticEchoCanceler 时尝试启用系统回声处理；不更改系统通信模式，不发起蓝牙 SCO。回声处理效果取决于设备。
- iPad 2021 不假设支持较新设备的系统回声消除，也不保证外放下完全消除电影对白。阈值和降音量用于降低干扰；耳机更可靠。
- 录音只在内存中处理，不保存或上传麦克风录音。只有确认后的文字经现有认证房间通道发送。

## 通信兼容

复用 `CHAT_MESSAGE`，客户端数据带 `source:voice`，`clientMessageId` 使用 `voice:` + UUID。现有服务器保存并转发 clientMessageId，因此旧服务无需升级、重启或迁移数据库。新客户端根据前缀识别语音弹幕；默认滚动四秒，上方三条轨道避开常规底部对白字幕。旧客户端仍可收到普通聊天文字。

服务端继续依据认证连接确定用户和房间，保留原有长度限制、限流和重复消息去重；客户端增加确认、房间校验、字数校验和待发数量限制。断线重试使用同一消息 ID，客户端按服务端 ID 避免重复显示。

## 验证范围

测试记录以最终构建日志和报告为准。核心测试覆盖：松手/识别结果不自动发送、修改后确认、取消、空文本和长度限制、房间变更、运输失败、重复确认、20 条消息去重、阈值和字尾保留、平滑音量恢复。服务端使用隔离临时数据库验证双向各 20 条消息、认证发送者和重复重试，未操作生产数据库。

Android 模拟器测试从APK中的模型开始真实首次准备，使用真实 AudioRecord 和离线模型，同时播放人工生成的测试片；这不等同于真实外放电影对白隔离测试。云端不能模拟用户的 AirPods Pro 2 路由、实际扬声器回声或长时间观影耗电。实际中文准确率、结束后 1–2 秒延迟目标、Atmos 输出、外放干扰、长时间播放表现仍需实机验收。此包标为测试版，不能宣称这些实机条件已经通过。


## iPad 0.5.1 修正

- 在启用语音时准备一次 playAndRecord 会话与音频图；每次按住/松开不再反复设置会话类别、首选输入、激活状态。仅按住时运行采集，关闭/后台/离房恢复原会话。
- 输入阈值改为电平提示，完整音频送入本地识别，不再硬清零小声或字头。iPad默认提示阈值0.003。
- 内置扬声器录音时平滑降至原音量8%，耳机仍22%；不更改播放进度或状态。
- 松手时有文字最多等待700ms收尾；无文字仍给本地识别3秒。空的最终/部分回调不清空已有文字，中途错误保留可编辑结果。
- 文字预览更新限制为每秒5次；未收到文字时显示具体识别错误或收音提示。
- 这些修正尚不能承诺外放回声完全被消除。实际识别率、音频切换卡顿必须以设备验证为准。


## Android 0.5.1 修正

中文模型随APK提供，首次启用只在本机校验、解压、载入，完全无需网络下载。显示准备阶段/已解压大小，提供取消准备；失败后可重新启用。APK因此增加约42MB。云端验证改为真实首次安装，不预灌模型。输入不再硬清零，空的最终回调和识别异常保留已有结果。

- iPad每次物理按住最多启动一次录音。识别错误或超时后，手指移动不会自动重新开始，须松手再次按住。

## 0.5.2 全屏与外放录音优化

- 两端外放录音平滑静音、耳机仅降音量；松手恢复到用户设定音量。0.48秒渐变从当前音量衔接，中途松手不会先跳回起始音量。iPad按显示帧更新、Android按动画帧更新，不操作影片进度。
- 全屏控制条独占画面下方区域，收起后电影恢复占满；不覆盖电影画面或底部字幕。
- 语音入口及按住说话位于全屏右下角；录音电平、识别结果及确认发送按需展开。
- 字幕导入/调整收进字幕工具菜单，播放音量通过扬声器按钮展开，保留全部实际操作。
- 顶部语音弹幕4秒改为5秒，文字弹幕8秒改为10秒；底部对白字幕时间轴不变。
- iPad语音回调使用独立队列，按住先反馈再开始准备；Android长按添加即时按下反馈，时间与输入状态文字仅在变化时更新，减少重复布局。

静音渐变结束前仍可能有短暂电影声音和房间回声，不能保证所有外放环境完全无干扰。蓝牙音箱可能被系统归类为蓝牙媒体输出，实际路由与听感仍需实机核对。本次不是引入回声消除。
