# 0.5.6 音轨、字幕菜单与播放控件

- 独立分支 fix/track-labels-chinese，继承0.5.5。
- iPad读取AVMediaSelectionOption的原始标题，兼容播放在HLS音轨名称中保留源编码/profile、channel layout及唯一音轨编号；桥接音轨标记输出编码。只改名称，不改音频处理。
- 内置字幕保留源标题，CHS/CHT或Hans/Hant、地区标记显示简体/繁体中文。没有标记时显示简繁未标明，不按序号猜测。语言菜单使用中文。
- Android依据Media3 Format显示中文语言、编码和声道数；声道数量推断5.1/7.1时标注“通常”。
- 字幕调整打开真实AVPlayer画面及设置并排的工作区，小屏上下排列；复用同一播放器、字幕对象，不另开播放会话。
- 字幕位置百分比按实际影片画面计算，排除播放器黑边，保持调整画面与全屏的相对位置。
- iPad进度条不再在首次拖动回调中覆盖目标，移除与Slider竞争的全屏零距离DragGesture，拖动期间阻止自动隐藏。访客仍需房主批准跳转。
- iPad使用MPVolumeView系统音量控件；录音ducking仍只作用播放器。
- 原生实机麦克风、扬声器及系统音量需用户安装确认；模拟器不能验证硬件系统音量。
