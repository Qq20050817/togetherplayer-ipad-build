# iPad PGS 原版位图解码适配：本地文件试验

- 已验证基线：feat/ipad-pgs-overlay-view-wiring-20261014 / bafd9629ce6294089e1026bfa32ab7037e84d0a1（CI 38536813979 成功）。
- 目标：观看使用原始 PGS 调色板位图叠加，AI 只使用 OCR 的字幕时间轴/SRT；不修改影片、不切换播放器字幕选轨，不影响现有服务端、Android 与其他服务。
- 这一阶段新增 OriginalPGSFileExtractor：仅对在 iPad 上有直接文件路径访问权的本地文件，在独立 FFmpeg 上限读取（256 MiB），严格匹配唯一 PGS 源轨，按影片时间生成原始调色板/矩形事件；经原有 PGSBitmapComposition、OriginalPGSBitmapOverlay 投放到播放画面。
- 本地字幕扫描不会使用云端或 OCR，OCR 的文字只供 AI 线索使用，屏幕有原版 PGS 位图时禁用重复 OCR 文本覆盖；实际无法提取的字幕保持原 AVPlayer 轨道的显示回退。
- 禁止自动重复读取普通远程 HTTP、百度网盘、路由器网络地址，因为二次读取高码率影片可能造成卡顿或额外流量。本阶段不支持此类源的原版 PGS 像素级显示，也不承诺完成所有电影或整个片长。256 MiB 读取上限可能只覆盖片头一部分，后续播放返回原播放器的字幕机制。
- 后续目标：从 PrismCore 的一次性原始 MKV demux 同时发出时间戳位图事件与 OCR 文本，无需重复读取视频流；消除部分片源显示退化，并验证重连、跳播、双语、字幕样式、HDR/4K。若需要修改上游依赖，应使用独立 fork 或可再现且有验证的适配，不应依赖本机临时修改。
- 验证：当前提交已触发独立 CI；在本阶段构建成功前不得声称编译通过，更不能声称所有片源可保留 PGS。真机真实 MKV/外部源测试仍需完成。
- 回滚：丢弃独立实验分支，继续使用通过 CI 的 bafd9629ce6294089e1026bfa32ab7037e84d0a1 或已经发布的 0.6.14 原 IPA；绝不覆盖当前已交付版本，也不重启服务。
