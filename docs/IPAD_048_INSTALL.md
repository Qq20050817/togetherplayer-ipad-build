TogetherPlayer iPad 0.4.8（构建 48）

用全能签沿用原证书签名，覆盖安装；“房间与片源”顶部确认 0.4.8。

本次更新：去掉字幕背后的矩形底色，改用白字和轻微黑色阴影，背景透明。内置文字字幕及外挂字幕使用同一显示方式。

新增“字幕调整 → 字体与间距”：系统／圆体／衬线字体，细体／常规／半粗／粗体；字距 -2 至 +6（步长 0.25），行距 -8 至 +20（步长 0.5）。向左收紧，向右增大，实时预览。字体、粗细、字距与行距会保存；恢复默认为系统常规、字距 0、行距 0。中文显示会依赖系统字体回退，不承诺与 Infuse 字体完全相同。

保留 0.4.7 字幕时间偏移（每次 0.1 秒）、垂直位置、字号、预览及恢复默认。字号和位置保存，换片或导入新字幕后重置时间偏移；调整只影响本机字幕。

仍保留字幕导入、音轨读取、Muse 恢复暂停、键盘适配、剩余时间和不同画质匹配。ASS/SSA 按文字显示；复杂排版与图片字幕不保证原样呈现。

验证：51 项原生单元测试、12 项界面测试全部通过。
