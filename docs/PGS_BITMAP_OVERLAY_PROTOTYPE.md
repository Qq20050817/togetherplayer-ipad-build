# PGS bitmap overlay candidate

Isolated iPad development only. This branch starts from successful build b17e863b747a5d7297850eeba5aa7d850be37f71.

The transparent palette compositor and its tests are experimental. They do not yet extract original PGS packets or connect to AVPlayer's subtitle selection, and cannot be treated as real-device acceptance.

Playback movie and AI-only OCR index remain separate. No server, Android, signing, or published release changes.
